## Naming convention

| Suffix | Meaning |
| --- | --- |
| *(none)* | Designed for **dark** surfaces |
| `-light` | Designed for **light** surfaces |
| `-tile` | Includes a rounded-square background tile |
| `-transparent` | No background — sits directly on the page |

## Usage

- **App icon / favicon:** use `icons/icon.svg` (dark tile) or `icons/icon-light-tile.svg` (cream tile). Use the `transparent` / untiled variants only when your background already provides contrast.
- **Docs & README headers:** `logos/logo-horizontal.svg` on dark, `logo-horizontal-light.svg` on light.
- **Text-only lockups:** the wordmarks, sized to the same visual height as the icon for inline use.
- **Social links & embeds:** `social/og-1280x640.svg`.
